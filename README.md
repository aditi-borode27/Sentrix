# 🔐 Sentrix – Secure Multi-Region Network Infrastructure

Sentrix is a secure multi-region infrastructure project designed to enable encrypted communication between geographically distributed networks. The project focuses on networking, security, system administration, monitoring, and DevOps automation using enterprise-grade practices.

---

## 🎯 Project Objectives

- Establish secure site-to-site connectivity across regions  
- Centralize identity, DNS, and certificate management  
- Implement monitoring, logging, and alerting  
- Automate application deployment using CI/CD and containers  
- Design a scalable and security-first infrastructure  

---

## 🏗️ Architecture Overview

- Multi-region network topology  
- Site-to-site VPN (LAN-to-LAN) connectivity  
- Centralized Active Directory and DNS  
- Reverse proxy–based secure web access  
- Centralized monitoring and logging  

---

## 🧩 Core Components

### 🌐 Networking & Security
- Site-to-Site OpenVPN  
- Firewall rules
- Encrypted inter-region communication  

### 🧑‍💻 Identity & Access Management
- Active Directory Domain Services (AD DS)  
- Centralized DNS  
- Certificate Authority (CA)  
- Read-Only Domain Controller (RODC)  

### 📊 Monitoring & Logging
- ELK Stack (Elasticsearch, Logstash, Kibana)  
- Uptime Kuma  
- Healthchecks.io  
- Email alerts for service health  

### 🚀 DevOps & Automation
- Jenkins CI/CD pipelines  
- Docker & Docker Swarm  
- Automated containerized deployments  

### 🌍 Web & Infrastructure Services
- Nginx (Web Server & Reverse Proxy)  
- Secure DNS-based routing  

---

## 🛠️ Tech Stack

- **Operating Systems:** Linux (Debian, Ubuntu), Windows Server  
- **Networking:** TCP/IP, DNS, DHCP, VLANs, NAT, VPN  
- **Security:** Firewalls, OpenVPN, Certificates  
- **DevOps:** Docker, Docker Swarm, Jenkins  
- **Monitoring:** ELK Stack, Uptime Kuma, Healthchecks.io  
- **Web Server:** Nginx  
- **Directory Services:** Active Directory, DNS, CA
